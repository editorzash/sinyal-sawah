# Sinyal Sawah — demo landing page

Demo tampilan landing page untuk **coworking & co-living** bagi nomad digital di Ubud, Canggu, dan Tabanan. Merek, harga, dan data di dalamnya fiktif.

Kebutuhan sistem yang diperlihatkan: **keanggotaan**, **tagihan bulanan**, dan **akses pintu**. Ketiganya bisa dicoba langsung di bagian Portal anggota.

## Bagian halaman
- Hero + kartu anggota (QR contoh)
- Lokasi (tab Ubud / Canggu / Tabanan)
- Sistem di balik layar (3 pilar)
- Paket & harga (pilih jenis, lokasi, kontrak; harga ikut berubah)
- Portal anggota interaktif: Keanggotaan, Tagihan (filter + alur bayar), Akses (QR berganti, coba buka pintu, cabut perangkat)
- Ringkasan sisi pengelola
- Acara komunitas, testimoni, FAQ, formulir gabung / kunjungan

## Catatan
- Satu file `index.html`, tanpa server, tanpa build. Font dari Google Fonts (ada cadangan jika gagal dimuat).
- Formulir dan pembayaran hanya tiruan; tidak ada data yang dikirim.
- Tanggal demo dikunci ke 13 Nov 2026 agar contoh tagihan terlambat tetap konsisten.
